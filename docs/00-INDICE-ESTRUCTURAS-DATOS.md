# 📚 Curso de Estructuras de Datos en Java

## Índice del Curso

Este curso está diseñado para aprender las estructuras de datos más importantes en Java de manera progresiva, desde las más básicas hasta las más avanzadas.

### 📖 Orden de Estudio Recomendado

1. **[01-Arrays.md](01-Arrays.md)** - Arrays (Arreglos)
   - La estructura de datos más básica y fundamental
   - Base para entender todas las demás estructuras

2. **[02-ArrayList.md](02-ArrayList.md)** - ArrayList
   - Evolución natural de los arrays
   - Arrays dinámicos más flexibles

3. **[03-LinkedList.md](03-LinkedList.md)** - LinkedList  
   - Introducción a las estructuras enlazadas
   - Diferencias con ArrayList

4. **[04-HashMap.md](04-HashMap.md)** - HashMap
   - Mapas clave-valor
   - Una de las estructuras más útiles

5. **[05-HashSet.md](05-HashSet.md)** - HashSet
   - Conjuntos únicos
   - Basado en HashMap internamente

6. **[06-Stack-Queue.md](06-Stack-Queue.md)** - Stack y Queue
   - Estructuras LIFO y FIFO
   - Conceptos fundamentales

7. **[07-TreeMap-TreeSet.md](07-TreeMap-TreeSet.md)** - TreeMap y TreeSet
   - Estructuras ordenadas
   - Árboles balanceados

### 🎯 Práctica Adicional

8. **[EJERCICIOS-LEETCODE.md](EJERCICIOS-LEETCODE.md)** - Ejercicios de LeetCode
   - 42 problemas específicos organizados por estructura y dificultad
   - Plan de estudio de 6 semanas
   - Problemas reales de entrevistas técnicas

## 🎯 Objetivos del Curso

- **Comprender** el funcionamiento interno de cada estructura
- **Aprender** los métodos más importantes y cuándo usarlos
- **Practicar** con ejercicios de diferentes niveles de dificultad
- **Desarrollar** intuición para elegir la estructura correcta

## 📋 Formato de Cada Lección

Cada archivo incluye:
- ✅ **Explicación conceptual** sencilla y clara
- ✅ **Ejemplos prácticos** con código
- ✅ **Métodos más importantes** con ejemplos de uso
- ✅ **6 ejercicios** graduales:
  - 2 ejercicios fáciles
  - 2 ejercicios de nivel medio  
  - 2 ejercicios difíciles

## 🚀 Cómo Usar Este Curso

1. **Lee cada archivo en orden** - Los conceptos se construyen sobre los anteriores
2. **Ejecuta todos los ejemplos** - Copia el código y pruébalo
3. **Resuelve los ejercicios** - Empieza por los fáciles y avanza gradualmente
4. **Experimenta** - Modifica el código para entender mejor el comportamiento
5. **Practica en LeetCode** - Usa la guía de ejercicios específicos para consolidar conocimientos

## 💡 Consejos para el Estudio

- **No te saltes los conceptos básicos** - Son la base de todo
- **Practica escribiendo código** - La teoría sin práctica no es útil  
- **Compara las estructuras** - Entiende cuándo usar cada una
- **Resuelve problemas reales** - Aplica lo aprendido en proyectos

¡Comienza tu viaje por las estructuras de datos! 🎉
